  • Description of the changes in this pull request:

    A list of device paths (devices=<btrfs device path>), data profile (dprofile=<btrfs data profile>), and metadata profile (mprofile=<btrfs metadata profile>) are added to disklayout.conf. Filesystem dependencies are set for all devices in the group. This takes advantage of the fact that, to mount a Btrfs filesystem spanning multiple devices, any device from the group can be used
    (long line shown wrapped here):

fs /dev/sda3 / btrfs
 uuid=888a6d32-dae2-47c2-9b5b-a3f7d6b06666
 label='fedora'
 nodesize=16384
 sectorsize=4096
 features=block-group-tree,extref,free-space-tree,no-holes,skinny-metadata
 devices=/dev/sda3,/dev/sdb1,/dev/sdc1
 dprofile=single
 mprofile=raid1
 options=rw,relatime,compress=zstd:1,discard=async,space_cache=v2,subvolid=256,subvol=/root
