gdha commented at 2026-10-13 13:42:¶

@jsmeix @dhoffend Renewed it:

# Inspect the current key
osc signkey Archiving:Backup:Rear

# Extend its expiration date (same key and fingerprint, new expiry)
osc signkey --extend Archiving:Backup:Rear

$ osc api /source/Archiving:Backup:Rear/_pubkey | gpg --show-keys
pub   rsa4096 2026-10-13 [SC] [expires: 2028-12-21]
      AFAB679489120B741A1DE72DA35FC8E0CA080173
uid                      Archiving:Backup:Rear OBS Project <Archiving:Backup:Rear@build.opensuse.org>

# To force a publish, trigger any event that causes one:
$ osc rebuild Archiving:Backup:Rear -r Debian_12
ok
