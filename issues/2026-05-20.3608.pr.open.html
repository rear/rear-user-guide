The lftp command needs to apply the user specified options prior to opening the URL, otherwise the options won't apply for the opening itself.
This is problematic when users use a custom program to connect, e.g. OUTPUT_LFTP_OPTIONS=( "set sftp:connect-program 'ssh -i /etc/rear/mykey'" )

The issue was introduced by commit c4ddb00f1f9eba7b036a6a54788080f2197badde.
