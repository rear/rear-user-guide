-   Description of the changes in this pull request:

The Forbidden to source error was ReaR's secure-sourcing guard
(is\_trusted\_write) refusing files that are writable by group or
others. Your host umask of 0002 produces rw-rw-r-- files, and those
permissions carry into the bind-mounted /rear tree inside the container.

Two changes made:

1.  Ran chmod -R go-w on the repo to clear the group/other write bits
    immediately.
2.  Added a permanent guard to tools/run-in-docker that runs chmod -R
    go-w "$rear\_toplevel\_dir" before the docker run loop, so this
    never recurs regardless of your umask or future checkouts.
