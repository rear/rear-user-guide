-   Description of the changes in this pull request: Duplicity workflow

    Furthermore, the non-default gpg options are not passed via
    duplicity anymore, but should be added to the ~/.gnupg/gpg.conf file
    instead.

only be used in 'recovery' time (default is always the latest full).
