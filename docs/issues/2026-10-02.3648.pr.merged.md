#### <img src="https://avatars.githubusercontent.com/u/1788608?u=925fc54e2ce01551392622446ece427f51e2f0ce&v=4" width="50">[jsmeix](https://github.com/jsmeix) commented at [2026-10-21 10:57](https://github.com/rear/rear/pull/3648#issuecomment-6314253480):

Despite that it can become tricky  
to properly unset local functions  
I would prefer to use local functions  
when a function is not sufficiently implemented  
so that it can be safely used globally / everywhere  
to avoid that locally intended specific helper functions  
could be misused as generic global functions, see  
<https://github.com/rear/rear/wiki/Coding-Style#functions>

When a local function is not unset in some cases  
nothing goes directly wrong because of this.  
It only results that in some cases this local function  
could be misused as a generic global function.  
As long as local functions get unset at the end of the  
intended scope (end of parent function / end of script)  
things should be usually "good enough" and missing  
unset calls can be easily added later as needed.
