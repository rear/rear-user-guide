#### <img src="https://avatars.githubusercontent.com/u/1788608?u=925fc54e2ce01551392622446ece427f51e2f0ce&v=4" width="50">[jsmeix](https://github.com/jsmeix) commented at [2026-09-16 12:11](https://github.com/rear/rear/pull/3637#issuecomment-5697202723):

With my recent  
<https://github.com/rear/rear/pull/3637/changes/4d0911f1abd8a7e4c7f50c24498480484d468066>  
I improved its user related behaviour  
(but no changes in actual functionality):

Do not report used unsupported filesystems as LogPrintError  
because the user may have excluded what belongs to it  
and then the LogPrintError message would needlessly  
still be shown to the user in any case.

Check if findmnt is available to show a generic fallback  
user information about unsupported filesystems  
if findmnt is not available.
