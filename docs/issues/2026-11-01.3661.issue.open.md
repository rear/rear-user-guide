### Additional information

In the extensive documentation for using ReaR with Duplicity and S3 as
the storage medium, the backup section clearly states that the GnuPG
keys are stored on recovery medium.

What isn't clear or addressed anywhere is where Duplicity obtains the
AWS keys for recovery.

If the recovery medium doesn't contain the AWS keys (put there by ReaR)
then there would have to be a way for duplicity to request them.

Can this please be made clear in the documentation?
