-   Description of the changes in this pull request:

bp.conf can have different syntaxes:

KEY = value  
KEY=value  
KEY value 1 2 3  
KEY = value 4 5 6

The current implementation accepts only the 1st one. If the key does not
contains space around '=' or has multiple values, it fails, and then the
recover do not complete (UUID are not updated to /etc/fstab for example)
