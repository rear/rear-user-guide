#### <img src="https://avatars.githubusercontent.com/u/1788608?u=925fc54e2ce01551392622446ece427f51e2f0ce&v=4" width="50">[jsmeix](https://github.com/jsmeix) commented at [2026-10-08 14:16](https://github.com/rear/rear/issues/3654#issuecomment-6061840102):

For scripts ASCII is mandatory.

For other files ASCII is recommended because it avoids  
any character encoding issues inside the recovery system  
while UFT-8 encoding normally provides no real benefit.

A file like MAINTAINERS is an exception because it is  
a real benefit to have person names from all countries  
written with the correct characters from their countries.

My above `find` output is the raw output.  
I did non filter out exceptional files (like MAINTAINERS)  
or false results lile "Perl script text executable".
