-   Impact: **Normal**

-   How was this pull request tested?  
    Manually recovered Debian 10 with XFS

-   Description of the changes in this pull request:  
    Currently XFS configs are not copied correctly in non-debug mode
    (not verbose mode) due to these quotes - `"$v"`.  
    However, applying XFS options is crucial in cases when XFS was
    created on old software and during the recovery newer software is
    used. In some cases it may lead to failures during GRUB
    installation. GRUB checks XFS features and returns an error when
    encounters unknown one.

#### <img src="https://avatars.githubusercontent.com/u/29474856?u=b3637dbf6b72d36a96742d81028e6361add0d388&v=4" width="50">[svlv](https://github.com/svlv) commented at [2026-02-21 10:27](https://github.com/rear/rear/pull/3571#issuecomment-3938572559):

How to reproduce in the terminal:

Wtih quotes it isn't copied:

    $ unset v; touch myfile;  cp "$v" myfile myfile~
    cp: target 'myfile~': No such file or directory

WIthout quotes it is copied as expected:

    $ unset v; touch myfile;  cp $v myfile myfile~
    $ file myfile~
    myfile~: empty
