## Summary

This is a heavily enhanced version of the existing `BACKUP=NBU`
support,  
bringing it up to date for Cohesity NetBackup (formerly
Symantec/Veritas).  
The original integration was a minimal reference implementation. This  
builds on it and turns it into a full recovery workflow.

It relies on NetBackup commands that have been around for a long time  
(`bpclimagelist`, `bprestore`, `bplist`, `bpclntcmd`, `nbcertcmd`,
True  
Image Restore, altnames). Using them properly removes the limitations
of  
the old integration, especially in ReaR's rescue environment.

## What's new

-   Host certificate enrollment in the rescue system (NBU 8.1+), with
    the  
    certificate state carried over to the recovered disk.
-   Automatic detection of the client startup mechanism (systemd, SysV  
    init, legacy xinetd).
-   Point-in-time restore picked from the real NetBackup catalog, with
    the  
    restore chain computed automatically.
-   True Image Restore support (`NBU_TRUE_IMAGE_RESTORE`, default true).
-   Restore from a different client (altname).
-   Handling of a changed hostname or primary server during recovery.
-   Safety checks at backup and restore time (client version, TIR
    backups  
    in the catalog, primary reachability, refusing primary/media
    servers  
    as clients).
-   Stricter `bprestore` error handling and a more complete rescue
    image.
-   Docs renamed to Cohesity NetBackup, plus a new user guide chapter.

## Testing

Tested end to end (backup, mkrescue, boot, recover) against a live  
NetBackup 11.2.0.1 primary with three client generations: RHEL 9  
(NBU client 11.2.0.1, systemd+PBX), RHEL 7.9 (NBU client 9.1, legacy  
xinetd) and SLES 15 SP7 (NBU client 11.2.0.1, systemd+PBX).
