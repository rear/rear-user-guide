I tried several approaches, but they did not work. Eventually, I
identified the root cause: the backup is stored on an NFS server.

After restoring the rescue image, we need to assign an IP address to the
server. Once the network is configured, the server automatically
connects to the NFS server and retrieves the backup files required for
data restoration.

If anyone requires the detailed recovery procedure, please let me know.
I can prepare an SOP for the complete restore process.

@20pa5a1203  
to automate special cases of network devices setup  
in the rescue/recovery system you may specify  
NETWORKING\_PREPARATION\_COMMANDS=( ... )  
as needed in your /etc/rear/local.conf  
see the description in usr/share/rear/conf/default.conf  
e.g. for ReaR 2.9 starting at  
<https://github.com/rear/rear/blob/master/usr/share/rear/conf/default.conf#L3822>
