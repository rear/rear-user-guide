-   Description of the changes in this pull request:

ISO output may be written to a writable medium (e.g. USB stick) which
should be protected against overwriting by "rear recover" as well.
Otherwise, ReaR would suggest to wipe the backup if at least one of the
disks is missing.

The majority of these changes have been written using Claude.

Just curious, can you please share the details of the test? Did the VM
have the ISO image on a (writable) virtual hard disk? Was the firmware
able to boot from an ISO 9660 filesystem on a non-optical drive? (I am
asking because while the firmware of "old-style" UNIX RISC hardware
(like OpenFirmware) is able to do that, aarch64 has PC
(Itanium...)-style UEFI and I thought that this would make a strict
distinction between partitioned disks and optical drives.)
