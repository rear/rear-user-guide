-   Description of the changes in this pull request:

    A list of device paths (`devices=<btrfs device path>`), data profile
    (`dprofile=<btrfs data profile>`), and metadata profile
    (`mprofile=<btrfs metadata profile>`) are added to
    `disklayout.conf`. Filesystem dependencies are set for all devices
    in the group. This takes advantage of the fact that, to mount a
    Btrfs filesystem spanning multiple devices, any device from the
    group can be used  
    (long line shown wrapped here):

     devices=/dev/sda3,/dev/sdb1,/dev/sdc1
     dprofile=single
     mprofile=raid1
